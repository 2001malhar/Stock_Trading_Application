# Stock Trading Application

## Overview
This project is a stock trading application that provides features for analyzing stock market trends, managing portfolios, and executing trades. It includes a graphical user interface (GUI) for user interaction and backend logic for handling stock data and transactions.

## Contents
- `src/` - Source code directory containing Java classes for the application:
  - `Main.java` - Entry point of the application.
  - `StockApiCall.java` - Handles API requests for stock data.
  - `controller/` - Contains controller classes for managing application logic.
  - `models/` - Defines data models for stocks and portfolios.
  - `view/` - GUI components for user interaction.
- `Historical/` - Historical stock data in CSV format.
- `portfolios/` - Sample portfolio data.
- `res/` - Resources such as documentation, images, and configuration files.
- `test/` - Unit test directory with test cases.

## Requirements
To run this project, ensure you have the following installed:
- Java (>= 11)
- IntelliJ IDEA or Eclipse (optional, for development)
- Maven (for dependency management)

## Features
- **Stock Data Analysis**: Fetch and visualize stock trends.
- **Portfolio Management**: Create and manage stock portfolios.
- **API Integration**: Fetch live stock data.
- **GUI Interface**: User-friendly interface for trading operations.
